# АВИОР CMS

Внутренняя система сервиса АВИОР (Москва, Можайское шоссе 4к1). Постепенно
заменяет ЛайвСклад: учёт ремонтов, клиентов, склада, финансов, интеграция
с сайтом по статусу ремонта, SMS-уведомления.

> Полное и всегда актуальное состояние проекта (инфраструктура, миграции,
> секреты, бэклог) — в [`PROJECT_STATE.md`](./PROJECT_STATE.md). Этот файл
> нужно читать в начале каждой новой рабочей сессии по проекту.

## Что уже готово

- Авторизация сотрудников (логин/пароль, сессии, пароли на bcrypt).
- Панель управления с сеткой модулей.
- **Клиенты** — база, поиск, история заказов, источник обращения (авито,
  яндекс, 2гис, google карты, сарафан, с улицы).
- **Заказы** — единый список с трёх точек входа (ремонт, сборка ПК, памятка
  по аккаунту), статусы (принят → диагностика → согласование → в ремонте →
  готов → выдан / отказ), лог смены статусов, комплектующие и услуги по
  заказу (с себестоимостью для расчёта прибыли).
- **Сборка ПК** — форма создания заказа, встроена как модуль CMS.
- **Памятка по аккаунту** — печатная форма Apple ID/Google; пароли и
  секретные ответы не сохраняются в БД, только на распечатанном листе.
- **Квитанция о приёмке** — печать в 2 экземплярах с гарантийными условиями,
  данные сохраняются в заказе для повторной печати.
- **Финансы** — выручка/себестоимость/расходы/чистая прибыль по периодам.
- **Аналитика** — источники клиентов, частые типы устройств, прибыльность.
- **Профиль и сотрудники** — смена своего пароля/имени, а администраторы
  дополнительно могут добавлять/удалять сотрудников, менять роли и
  сбрасывать пароли (`employees.php`).
- Заготовка **SMS** — пока не подключён провайдер, сообщения логируются.
- Публичный **API статуса ремонта** (`public/api/status.php`) — для виджета
  на основном сайте (пример в `docs/status-widget-example.html`).
- **API для мобильного приложения** (`public/api/mobile/*.php`) — токен-
  аутентификация, клиенты, заказы, смена статуса. Полная спецификация и
  готовый Kotlin/Retrofit-каркас — в [`docs/MOBILE_API.md`](./docs/MOBILE_API.md).

## Стек

PHP 7.4+/8.x (без фреймворка, только PDO) + MySQL 5.7+/8.0. Никаких
build-шагов и composer-зависимостей — можно просто скопировать файлы на
хостинг и открыть в браузере.

## Структура проекта

```
cms-avior/
  config/
    config.example.php   ← скопировать в config.php и заполнить
  public/                ← корень сайта (document root указывает СЮДА)
    index.php            ← панель управления
    login.php / logout.php / setup.php
    clients.php / client_view.php
    repairs.php / repair_new.php / repair_view.php
    smeta-sborka-pk.html ← форма сметы на сборку ПК
    api/status.php       ← публичный API статуса ремонта
    assets/css/style.css
  src/                    ← общий PHP-код (не должен быть доступен напрямую из браузера)
  sql/schema.sql          ← схема базы данных
  docs/                   ← вспомогательные материалы, примеры
```

Подробная инструкция по установке на сервер — в `docs/DEPLOY.md`.

## Локальная разработка

Если понадобится проверить локально:

```bash
cd cms-avior
php -S localhost:8000 -t public
```

(нужен PHP 7.4+ и настроенная в `config/config.php` база MySQL,
доступная с этой машины).
